WhatsClean

A free, private WhatsApp storage cleaner for macOS. Review and remove unwanted images, videos, audio, and documents without keeping another app running in the background.

Download for Apple SiliconView on GitHub

Use it and close it

Open WhatsClean when you need it, clean your WhatsApp storage, and quit. It does not need to stay open.

Lightweight Auto (7d)

Optionally let macOS run a brief daily task that moves WhatsApp media older than seven days to the Trash—without continuous RAM or CPU use.

Private by design

Your files are scanned locally and unwanted items are moved to the Trash. WhatsClean does not upload your media.

Install with Homebrew

brew install --cask vviniciusbarreto/tap/whatsclean

Simple and reversible

Preview media before cleaning, save anything you want to keep, and recover recently removed files from the macOS Trash. Available in English and Brazilian Portuguese.
